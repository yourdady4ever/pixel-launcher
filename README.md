# Jostin OS

Pantalla de inicio propia para Android (Pixel 9), en estilo monocromático.

- Día de la semana en letras grandes con fecha y hora
- Cinco fondos animados dibujados con código: Olas, Niebla, Noche, Panal y Rojo
- Selector de fondos con tarjetas inclinadas (mantén presionado el fondo)
- Calendario al tocar el reloj; ajustes al mantenerlo presionado
- Dock con 6 apps a elegir y cajón con buscador (desliza hacia arriba)
- Paneles: calculadora de obra, modo estudio, pendientes y acceso a Claude

Cada vez que se sube un cambio a `main`, GitHub compila el APK y lo publica en Releases.
